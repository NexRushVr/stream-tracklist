# Usage:
#   python stream_songs.py --streamer-mode --streamers-file daily_streamers.txt
# --streamer-mode skips VODs already in logs/<handle>.json, so a daily run only
# scans each streamer's NEW VODs. The first run backfills their recent history.

# Spotify note: a full first run can exhaust Spotify's daily search quota. That
# no longer hangs — recognitions are saved to *_matches.jsonl and unresolved
# tracks fall back to /search/ URLs. The next day, run:
#   python stream_songs.py --backfill-spotify --streamers-file daily_streamers.txt
# (or just `--backfill-spotify`) to fill them in without re-scanning audio.
